# ①課題名
すもおせろ（手押し相撲オセロリッチver）

## ②課題内容（どんな作品か）
- 手押し相撲とオセロを掛け合わせたゲームです。
- さまざまな年代の人が楽しめるゲームです。

## ③工夫した点・こだわった点
- 手押し相撲の勝敗が決定したときに太鼓の音が鳴るようにしました。
- 一発逆転マスを選択し、コマが一気に自分の（相手の）ものになるタイミングでお相撲さんがジャンプするように設定しました。
- コマの数ではなく、点数で勝敗が決まるようにしました。
- 黄色いボタンの表示をマスの選択前後で変化させるようにしました。（「はっけよーい」→「のこった！」）
- 張り手を2回使用できるようにし、ここぞという場面で張り手ボタンを押すと自分のお相撲さんの勝率が70％になるようにしました。
- お相撲さんの負け方にバリエーションを持たせました。
- 一発逆転マスに加えて、お休みマス、待ったマス、入れ替わりマスを設定しました。
- お相撲さんの勝負時間を短くできるボタンを設定しました。

## ④難しかった点・次回トライしたいこと（又は機能）
- 面白さを増すために様々な機能を追加しようと思いましたが、追加しすぎてしまうと逆に複雑になってしまうので、その塩梅が難しかったです。
-運要素を弱めて、本当のオセロのように相手との心理戦を楽しむモードも作って、ユーザーが運要素と心理要素のバランスを選択できるようにしてみたいと思いました。（手押し相撲の勝率を高める、張り手のような手札のバリエーションを増やすなど）
